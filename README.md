# TravelBlog AI (autoDiary)

여행지 이름을 입력하면 Gemini API로 블로그용 여행 후기 글·이미지·해시태그를 자동 생성해주는 도구.

## 구성
- `index.html` — 단일 페이지 도구

## 주요 기능
- Gemini API Key를 브라우저 localStorage에 저장해서 사용 (서버에 키를 보내지 않음)
- 여행지 입력 → 1인칭 구어체의 2단락 블로그 본문 + 이미지 URL 2개 + 해시태그 12개 이상 생성
- "과장된 감탄 표현 금지, 소소한 현실 디테일 포함" 등 자연스러운 블로그 말투를 위한 프롬프트 규칙 내장
- 이미지 포함 레이아웃 미리보기 + 섹션별/전체 복사 기능

> `autoBlog`(TripWriter)와 컨셉이 유사하지만 별도 구현체.
